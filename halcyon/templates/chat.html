L3 — MCP (M6 tool-description poisoning · token scope)

Iggy calls the core-banking and CRM tools over MCP servers.

See the protocol — MCP Inspector (local deploy)

Eiger's MCP servers speak Streamable-HTTP at /mcp — core-banking on :9001, crm on :9002. Both ports are published (this host and a local deploy), so point Inspector straight at them — replace <eiger-host> with this app's host (localhost on a local run):

npx @modelcontextprotocol/inspector
# In the UI:  Transport = "Streamable HTTP"
#             URL = http://<eiger-host>:9002/mcp   (crm — the poisoned one)
#             URL = http://<eiger-host>:9001/mcp   (core-banking)

Watch tools/list return get_customer with its poisoned description, then call it. (Network-exposed, unauthenticated MCP is deliberate here — it's the whole M6 lesson.)
